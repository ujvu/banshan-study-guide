1路线总览与时间轴

时间为建议值（按 4—5 岁孩子步速 + 每站任务停留估算），现场以孩子状态为准，宁可慢、不可赶。

一句话路线

南门广场·主入口 →（停车场公共厕所）→ 第一个路口（绿色指示牌·问樵处）→ 石阶上行（竹林红牌）→ 竹林岔路口 → 台阶上行汇合（主线绿道指示牌）→ 下行回到柏油绿道（桥与路灯）→ 集合上车。单向不回头，孩子记路只记"牌子"。

2七个实走点位 · 看图认路

照片为 2026-11 踩点实拍。「怎么认路」一栏是给带队老师现场定位用的——照片里有什么，我们就找什么。

① 南门广场 · 主入口点击放大看指示牌

入口 · 全天的集合点与撤离点

类型：集合/入园 · 地面平整宽石板 · 无人车混行段
👀 照片里有什么
  • 正前方石板主步道直入园内，两侧木质解说牌（导览图＋景点介绍）。
  • "半山国家森林公园 欢迎您"横幅；黑色金属"内部车辆通道"指示牌；P 停车标识（发光字，文字现场再看）。
  • 入园段与内部车辆通道相邻，有人车混行。
🗣 带班老师这么说

"看，我们走进的这扇门写着『半山国家森林公园 欢迎您』。先在门口的地图上找一找——我们要去的竹林在哪个方向呀？"

🔎 研学任务
  • 在入口导览图上指一指主绿道与竹林的位置（让孩子用手指"点"在图上）。
  • 数一数解说牌上一共有几块图、几个景点名。
⚠️ 安全要点
  • 点名①：贴好姓名贴再入园；总人数/男生/女生分别记一次。
  • 过内部车辆通道时牵手、靠右、一次一组通过，不让孩子在车道边跑。
  • 入口是撤离点：随时告诉孩子"走错了就回到有欢迎横幅的地方"。
② 停车场 · 公共厕所点击放大看指示牌

最近的厕所（就是停车场）

类型：服务点 · 入园后第一站 · 洗手/补水/整队
👀 照片里有什么
  • 绿色+白色指示牌：竖排"公共厕所"＋男女图标＋"TOILET"＋右转箭头。
  • 旁边是沥青车行道、一棵大树和一只大号垃圾桶。
  • 此点是离停车场最近的一处公厕；主线绿道牌上还标有"公共厕所 200m"。
🗣 带班老师这么说

"出停车场我们先去洗手间。洗小手要搓够 20 秒哦——一起数：一、二、三……再看牌子，'TOILET'是英语的厕所，它在告诉我们往哪边走。"

🔎 研学任务
  • 找一找：牌子上有几种颜色？几个箭头？箭头指的方向和我们走的一样吗？
  • 看看路边的垃圾桶：我们手里的纸巾要丢进哪一个？（垃圾不落地，垃圾袋带回园所）
⚠️ 安全要点
  • 入厕必须分组陪同：男生一组、女生一组，老师分别带到门口，不把孩子单独留在外面。
  • 洗手台人多时分组轮流，避免孩子着急拥挤。
  • 此点人流大、车来车往：不站在车道边拍照集合。
③ 第一个路口点击放大看指示牌

第一个路口 · 全程第一处分叉

类型：路口/讲解点 · 绿色多向指示牌 · 石板路
👀 照片里有什么
  • 绿色多向指示牌：右向一块写着"问樵处"（牌面除中文外还有英文等外文），左侧还挂着 3 块向左的牌子。
  • 石板路从牌前继续伸进竹林；路右侧有一块花岗岩标柱（石碑），左侧远处可见石阶。
  • 照片里已有大人带孩子经过——这里就是最容易走错的点。
🗣 带班老师怎么说

"这块绿色的牌子在告诉我们路——有箭头的地方就是路标。'问樵处'的'樵'是砍柴的人，意思是向住在山里的老人问路。我们把小手牵好，跟着牌子走。"

🔎 研学任务（任务卡 A：标识与方向）
  • 数一数这块路牌一共有几块牌子、几个箭头（右边 1 块写着"问樵处"，左边还有 3 块）。
  • 找"公共厕所"三个字在第几站牌子上出现过（预告第 7 站）。
  • 做一次"路标小侦探"：走过后每到一块牌子就问"这块牌子在指什么？"
⚠️ 安全要点
  • 必停、必点名（点名④）。分组站好、讲完路线再走。
  • 队伍过路口排成牵手链：老师前后各一人，中间老师牵孩子。
  • 路口车辆与自行车多，停下先看两边再过。
④ 石阶上行点击放大看红牌

石阶上行 · 起步爬升

类型：爬升段 · 石阶（带青苔）· 毛竹林
👀 照片里有什么
  • 连续石阶穿过竹林与乔木；石面有青苔，坡度明显。
  • 两侧毛竹成片，竹干笔直、有明显竹节。
  • 竹林里挂着红色警示牌，白字写着"禁止挖掘"。
🗣 带班老师怎么说

"台阶上绿绿的一层是苔藓，像给石头穿了件棉袄——踩上去有点滑，所以我们一级一级慢慢走。看这根竹子，它身上一圈一圈的，像竹子的'腰带'，那叫竹节。"

🔎 研学任务（任务卡 B：竹林观察）
  • 摸一摸竹节："竹子的腰带硬不硬？"
  • 看竹皮上的一层白粉："这是竹子自己涂的'防晒霜'哦。"
  • 数一数脚下落叶有几层：落叶多说明这里的土是活的。
⚠️ 安全要点（本次最大风险点）
  • 一步一台阶：不跳级、不并排、不推挤、不跑跳。
  • 牵手：孩子一只手牵老师，另一只手可扶栏杆；老师走在孩子下坡侧的前方。
  • 青苔＋落叶＝滑：鞋底必须防滑（凉鞋、拖鞋一律不允许）。
  • 把红牌读给孩子听并解释：不折竹、不摘叶、不挖土。
  • 每上 10–15 级停一次，问"累不累"，让孩子自己说要不要歇。
⑤ 竹林岔路口点击放大看地面

竹林岔路口 · 向上或向左

类型：岔路 · 无路牌 · 坡地松针落叶层
👀 照片里有什么
  • 坡地上成片的毛竹，竹皮光滑、带白粉；地面厚厚一层落叶与松针。
  • 坡面向一侧倾斜，光斑斑驳；没有明显的路牌。
  • 向上可继续走竹林登顶方向，向左是另一条路——孩子分不清，非常容易走错。
🗣 带班老师怎么说

"这里有两条路，我们不走岔的那一条——跟着前面的老师走。手放在前面老师的手上，一个跟着一个。"

🔎 研学任务（任务卡 C：声音与气味）
  • 听：闭上眼睛 30 秒，说出你听到的 3 种声音（风、鸟、脚步、落叶）。
  • 闻：闻一闻泥土、竹叶、树皮的气味，说说像什么。
  • 找：落叶里找小虫咬过的洞、羽毛、树枝，找到了不捡起来，指给老师看。
⚠️ 安全要点
  • 必停、必点名（点名⑤）：老师先确认方向，再让队伍通过。
  • 不擅自拐弯：反复强调"只走有老师的那条路"。
  • 竹林遮挡视线，前后间距不超过两个身位，老师回头就能看见每一个孩子。
  • 坡地松针落叶滑：不跑、不跳、不在坡上玩滑梯。
⑥ 台阶上行 · 与竹林汇合点击放大看四个箭头

台阶上行 · 与竹林汇合（"主线绿道"牌）

类型：汇合点/方向锚点 · 石柱指示牌 · 台阶旁
👀 照片里有什么
  • 木柱＋深色面板："半山森林公园绿道 · 主线绿道"。
  • 牌上四个方向：→ 龙山水榭 100m、↑ 游客中心 200m、← 公共停车场 200m、↑ 公共厕所 200m。
  • 牌子右侧是继续上行的石阶；牌下沿有 5 个红色禁令图标。
🗣 带班老师这么说

"我们回到'主线绿道'啦！这是今天最重要的路标——记住它，回来的路和上山的路都在这块牌子这里。你能找到写着'公共厕所'的那一行吗？箭头指的方向和我们要回去的方向一样吗？"

🔎 研学任务
  • 找出 4 个箭头分别指哪里，比较"公厕"和"停车场"两个方向有什么不同。
  • 数一数牌子上有 5 个红色禁令标志，说说看哪个最好认。
  • 认方位：向上 / 向下 / 左 / 右——这是幼儿园里学方位的好机会。
⚠️ 安全要点
  • 全员到齐再走（点名⑥）：这是撤离路线的"锚点"，人齐了才继续。
  • 台阶与柏油路交界处容易踩空，老师先下、孩子在中间、老师最后下。
  • 牌子旁是路口：不在指示牌下停留聚集，靠边站。
⑦ 下行回到主线绿道点击放大看桥与灯

下行回到主线绿道（桥 · 路灯）

类型：下山平缓段 · 柏油路 · 有桥与护栏
👀 照片里有什么
  • 两排仿古路灯，灯柱上挂着装饰挂件；路面是柏油（沥青），与石板路手感不同。
  • 左侧是跨水面的石栏杆（桥）与花池，右侧是园区建筑与围栏。
  • 此段平缓好走，是做总结分享、洗手、整队上车的最佳位置。
🗣 带班老师这么说

"我们下山啦！脚下的路从石板变成黑黑的柏油，声音也不一样了——石板是'哒哒'，柏油是'噗噗'。看桥上水里有没有倒影呀？"

🔎 研学任务
  • 比一比：石板路和柏油路，踩上去哪个软？哪个声音响？
  • 桥上找倒影、找水面上的落叶，比一比哪片叶子最大。
  • 总结分享：今天我们一共看见了几块路牌？（提示：绿色那块 + 主线绿道那块 + 厕所那块）
⚠️ 安全要点
  • 柏油路下坡快，慢走、不跑；下坡牵手改成前后手搭肩膀。
  • 桥有护栏：不趴在栏杆上、不攀爬、不把身体探出去。
  • 分享环节统一在绿化带外侧，不坐车道、不追跑。

3安全要点

先看红线，再看分项。带班老师人手一条，出发前互相念一遍。

⛔ 三条红线（违反即停）
  • 禁烟禁火：公园设有森林防火监控；不携带火种、不玩打火机、不用明火（含自带蜡烛香烛）。
  • 不投喂、不追赶野生动物：园内记录野生动物 27 目 58 科 166 种，猛禽常在高树活动。
  • 不折竹、不摘花、不挖土、不捡地上的果子吃（竹林内有红色警示牌，务必给孩子读一遍）。
1不离队伍，老师身边三步内
2上下台阶一律牵手
3不推挤、不并排、不跑跳
4青苔石阶慢慢走
5路口停下再点名
6不折竹不摘花不挖土
7不捡地上的果子吃
8不摸不喂野生动物
9不带火种、不吸烟
10走失原地等，不自己找路
🪜台阶与坡地（今天的主要风险）
  • 孩子单手牵老师，不松手；下坡时老师站在孩子前下方。
  • 石阶带青苔、地面有落叶与松针，禁止穿凉鞋、拖鞋、帆布鞋；运动鞋最佳。
  • 不跳级、不并排走、不在台阶上追跑；孩子说累就原地停一停再走。
  • 竹林岔路无路牌：停—点名—确认方向—再出发，四步固定流程。
🔎防走失（四—五岁高发）
  • 人少的地方绝不落单：厕所、岔路口、台阶中途都必须有老师。
  • 孩子统一穿醒目颜色（黄色/橙色外套）、姓名贴写上班级与老师手机号。
  • 教孩子一条保命指令："站着不动、原地等、看到老师就举手"，入园第一天反复演练。
  • 走失处置：孩子原地蹲下不乱跑 → 老师原地喊名并举起班级牌 → 1 分钟无果 → 一名老师原地守候，另一名沿原路回找 → 求助公园出入口值守点 → 10 分钟无果立即报警。
  • 手机统一调成最大音量，老师手机号互相存好；不让孩子独自拿手机。
🌦天气与体力（出发前看两遍天气）
  • 雷雨/暴雨/台风预警 → 直接启用 C 保底版或改期，不在林下停留。
  • 高温预警：提前 20–30 分钟出发，缩短竹林段，每 20 分钟补水一次（少量多次，别等口渴）。
  • 秋冬山顶与林间风大，每人带一件外套；出汗后先擦干再吹风。
  • 雨天石阶极滑，直接改走柏油主线绿道（主线绿道牌 → 游客中心/公共厕所方向都有平缓路段）。
  • 体力差的宝宝：老师背负上坡，提前在第 5 站休息一次；宁可少走，不要硬撑。
🧼卫生与礼仪
  • 入园后先洗手（第 2 站），吃饭前再洗手一次；纸巾自备、湿巾随身。
  • 垃圾不落地：纸巾、果皮统一入袋，垃圾袋带回园所，不留在园内。
  • 不捡地上的果子吃（园区常有掉落物，可能有虫或农药）；不喝不明来源的水。
  • 孩子想摸植物时，先问老师"可以摸吗"，养成先观察、再触碰的习惯。
📣组织与点名（四点四清）
  • 分组 4–5 人一组，每组一名组长（成人或大孩子），组内手牵手。
  • 点名 7 次：① 集合 ② 入园 ③ 厕所后 ④ 第一个路口 ⑤ 竹林岔路 ⑥ 主线绿道 ⑦ 出园上车。
  • 每次点名念名字＋看脸，不能只举手。
  • 收尾流程：整队 → 洗手 → 分享 → 带回班级 → 交还姓名贴与任务卡 → 清点物资。

4研学任务卡（人手一张 / 每组一张）

围绕本次实走路线设计，全部可在路边完成，5–8 分钟一站。四—五岁的重点是"说"和"指"，不用写字。

任务卡 A · 标识与方向
  1. 找一找：从入口到竹林，一共看见几块绿色的路牌？每块牌子上有几个箭头？
  2. 读一读：牌子上有没有写着"公共厕所"的那一行？在第几块牌子上？
  3. 指一指：这块牌子指向的方向，和我们要走的方向一样吗？
  4. 说一说：如果迷路了你该找什么？——"找牌子"。
回家说什么："今天有块绿色牌子，箭头指的方向我们去过了。"
任务卡 B · 竹林观察
  1. 摸一摸：摸到竹节了吗？它硬不硬？像不像竹子的腰带？
  2. 看一看：竹子上白白的一层是什么？（竹子自己的"防晒霜"）
  3. 数一数：脚下落叶有几层？厚厚一层说明这里的土很"舒服"。
  4. 找一找：落叶里的虫洞、羽毛、树枝——指给老师看，不要捡。
回家说什么："毛竹的竹节像腰带，地上落叶有好多层。"
任务卡 C · 声音与气味
  1. 听一听：闭上眼睛 30 秒，说出你听到的 3 种声音（风、鸟、脚步、落叶）。
  2. 闻一闻：泥土、竹叶、树皮的气味像什么？
  3. 比一比：石板路和柏油路，踩上去哪个软、哪个声音响？
  4. 找一找：桥上的水里，哪片落叶最大？
回家说什么："我听见了三种山里的声音。"

返园延伸（带回教室的三个小任务）

  • 把捡到的落叶做成自然观察记录，接《秋天的颜色》主题。
  • 把任务卡上的"路牌地图"画出来：今天经过的 3 块牌子分别写了什么？
  • 认识半山：半山本名皋亭山，"半山观桃、蚕花庙会、半山泥猫"是这里的老习俗；园里还有半山泥猫非遗体验馆，可另安排一次。

👤 走失
  1. 孩子原地蹲下不乱跑，老师原地喊名、举班级牌。
  2. 1 分钟无果：一人守原地、一人沿原路回找（重点：第 3 站路口、第 5 站岔路、主线绿道牌）。
  3. 求助公园出入口值守点／园方服务台。
  4. 10 分钟无果：报警 110，说明入口、路线、孩子衣着。
🦶 摔伤 / 擦伤
  1. 先看能不能走：能动 → 扶到安全处坐下；不能动/疑似骨折 → 不搬动、就地垫高并叫 120。
  2. 擦伤：清水冲洗 → 碘伏棉签 → 创可贴（物资里带）。
  3. 头部磕碰：立即送医，当天告知家长与园所。
⛈ 雷雨
  1. 听到雷声立刻离开林下、竹林和高树，往开阔的柏油路面撤。
  2. 不要在大树、灯柱、指示牌下停留（照片里的竹子、路灯都容易招雷）。
  3. 点清人数、就近到建筑物或管理用房避雨，雨停再走。
  4. 预警天气直接启用 C 保底版或改期。
🥵 中暑 / 脸色不对
  1. 移到阴凉处、解开衣领、少量多次补水（不要一次猛灌）。
  2. 物理降温：扇风、擦汗、凉毛巾敷额头。
  3. 情况不缓解或叫不醒 → 120，并通知家长与园所。
🐜 虫咬 / 蜂虫
  1. 普通蚊虫叮咬：清水洗净 → 炉甘石洗剂/清凉油，有过敏史的提前用药。
  2. 蜂蜇：先刮掉蜂刺（不要揉搓），冷敷，呼吸困难立刻 120。
  3. 发现蜱虫附着：不要硬拔，用镊子夹住靠近皮肤处缓慢拔出，消毒并就医。
  4. 全程不投喂、不拍打动物。
😰 情绪崩溃 / 哭闹不止
  1. 蹲下与孩子平视，先处理情绪再谈道理；给"喝水、休息、抱一抱"三个选项。
  2. 安排一名老师陪在旁边，其余孩子由老师带着继续前移（避免全队被拖住）。
  3. 允许原路返回到柏油路坐一会儿，不是失败，是正确选择。
