# 中班研学提示网页（半山国家森林公园 · 踩点实走版）

## 🌐 公网地址（已发布）

**https://ujvu.github.io/banshan-study-guide/**

- 免费 HTTPS，任何人可访问，手机浏览器打开即用，无需下载
- 仓库：https://github.com/ujvu/banshan-study-guide （公开仓库）
- 由 GitHub Pages 托管，`main` 分支根目录的 `index.html` 即线上页面
- **更新方式**：在本目录改 `template.html` → `python3 -B build.py` → 把生成的成品复制为仓库根目录 `index.html` → `git add/commit/push`，Pages 约 1–2 分钟自动生效
- **下线方式**：`gh api --method DELETE repos/ujvu/banshan-study-guide/pages`，或直接删除仓库
- 仓库内 `源文件/` 保存了可编辑模板、构建脚本与压缩后的 7 张照片，换台电脑也能重建

## 交付物

| 文件 | 说明 |
|---|---|
| `半山国家森林公园-中班研学提示.html` | **成品**。单文件网页（约 2.9MB），7 张踩点照片已内嵌，双击即可用浏览器打开；手机离线也能看；可直接发微信/邮件 |
| `template.html` | 网页源文件（HTML+CSS+JS）。改内容编辑这个 |
| `build.py` | 把 `template.html` 里的 `{{IMG_xxxx}}` 占位符替换成图片 base64，生成成品单文件 |
| `build/IMG_xxxx.jpg` | 压缩后的 7 张照片（最长边 1200px，JPEG q70），与点位 ①—⑦ 一一对应 |
| `预览-电脑端.png` / `预览-手机端.png` | 渲染预览图 |

## 改内容并重新生成

```bash
cd 项目/秋游-半山国家森林公园/研学提示网页
python3 -B build.py
```

（`-B` 是为了不产生 `__pycache__`；本目录在 OneDrive 文件提供程序里，删缓存目录会超时。）

## 页面结构

1. **60 秒速览** — 集合点／最近厕所／喝水点／最易走错的点／走失处置／三条红线
2. **路线总览与时间轴** — 一句话路线、强度三选一（A 精简 / B 推荐 / C 保底）、9 个时间节点
3. **七个实走点位** — 每站：实拍图 + 「照片里有什么」＋「带班老师怎么说」＋「研学任务」＋「安全要点」
4. **安全要点** — 三条红线、十条铁律、台阶与坡地、防走失、天气与体力、卫生礼仪、四点四清点名
5. **研学任务卡** — A 标识与方向 / B 竹林观察 / C 声音与气味，各带「回家说什么」
6. **行前清单** — 教师物资（可勾选、进度保存）、家长须知、现场打卡（可勾选）、出发前须向园方确认
7. **应急处置卡** — 走失／摔伤／雷雨／中暑／虫咬／情绪崩溃，110·120·119 + 待填电话栏
8. **附录** — 望宸阁登顶线（备选）与信息来源、口径差异说明

## 使用要点

- 顶部 **「打印」** 按钮只输出一页《随身速查卡》（点位对照表 + 十条铁律 + 走失处置 + 电话栏），每位老师一张
- 右上角 **A− / A+** 调字号；**点照片**可全屏放大看路牌
- 勾选进度存在浏览器本地（localStorage），换设备不同步
- 页面可离线：文件发到手机后用浏览器打开即可，不依赖网络

## 口径提醒

- 门票、开放时间、园方救援电话等公开资料未载明的，一律留空并列入"出发前须向园方确认"，**不猜不填**
- 园区面积有"约 172 公顷"与"852.91 公顷"两种口径；望宸阁高度有 42 米与 45 米两种口径，本网页不取单一数字作结论
